# Overview

Nail.ai project is pSEO project that help to find an idea of manicure and pedicure.

## Stack
- TypeScript
- Astro.js
- Keystatic CMS

## URL structure

```txt
/
{manicure|pedicure}/
{manicure|pedicure}/comaprison/{type}-vs-{type}/
{manicure|pedicure}/guide/{type}/
{manicure|pedicure}/{color}/
{manicure|pedicure}/{type}/
{manicure|pedicure}/{occasion}/
{manicure|pedicure}/{season}/
```

type: nude, french, etc.
